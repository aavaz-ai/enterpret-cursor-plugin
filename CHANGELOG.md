# Changelog

All notable changes to this plugin will be documented here.

## 0.2.0

- The `enterpret` MCP server now points at `https://mcp.enterpret.com/mcp`, the one public Enterpret MCP URL. The `wisdom-api.enterpret.com` URLs are deprecated.

## 0.1.0 — initial scaffold

- Logo: Enterpret-like mark on a white tile (brand indigo `#5B4BFF`).
- Added the `enterpret` MCP server pointing at `https://wisdom-api.enterpret.com/server/mcp`.
